# ja-sunao

Claude が書く日本語から、AIらしい言い回しと構成を抑制するプラグインです。
書き終えてから直すのではなく、書いている最中からルールを適用します。

ドキュメント、コードのコメント、コミットメッセージ、PRの本文が対象です。

## 処理内容

セッションの開始時に、日本語で書くときのルールを読み込みます。
ルールは [core-rules.md](skills/ja-sunao/references/core-rules.md) にあります。

Claude がファイルを書くと、チェック用のスクリプトが実行されます。
誤検出の少ない項目（定型の締め、全角ダッシュ、「**ラベル**:」型の箇条書き、順序を示さない文頭の「まず、」など）が検出されると、Claude に差し戻して直させます。
それ以外は助言として伝えるだけです。
同じファイルで差し戻すのは2回までです。

| 対象 | チェックの内容 |
|---|---|
| `.md` / `.mdx` / `.txt` | 言い回しと構成。要修正は差し戻す |
| コードのコメント | 言い回しだけ。助言のみ |
| コミットメッセージ、PRのタイトル | 言い回しだけ。要修正は実行前に中止する |
| PRの本文 | 言い回しと構成。要修正は実行前に中止する |

改行もチェックします。
文が続いて80字を超える行、4文以上続く行、空行なしで6行以上続くまとまりがあれば、句点で改行するよう助言します。
箇条書きの項目の中も対象です。
チャットの返信には hooks のチェックが適用されないので、ルールだけで抑制します。

既存のファイルを編集したときは、書き足した部分だけをチェックします。
人が書いた文章で差し戻されることはありません。

既存の文書を直したいときは、「AIっぽいところを直して」「この文書を診断して」のように頼むと `ja-sunao` スキルが使われます。
診断だけ（書き換えなし）とリライトの2つに対応しています。

## 導入

Claude Code では、プラグインとして入れると hooks、スキル、スクリプトがすべて有効になります。

```
/plugin marketplace add penta-air/ja-sunao
/plugin install ja-sunao@ja-sunao
```

ほかのエージェント（Cursor、Codex など）では、スキルだけを入れられます。

```
npx skills add penta-air/ja-sunao
```

この場合 hooks は入らないので、自動のチェックと差し戻しはありません。
スキルに書いてある自己チェックの手順で、同じ確認を Claude 自身が行います。

チェック用のスクリプトは Node.js 18 以上で動きます。
外部のパッケージは使っていません。

## チェックの手動実行

hooks を使わずに、既存のファイルをまとめてチェックしたいときや、CIに組み込むときに使います。

```
node skills/ja-sunao/scripts/scan.mjs docs/design.md
echo "キャッシュを刷新——高速化" | node skills/ja-sunao/scripts/scan.mjs --kind commit
```

`--json` を付けると結果をJSONで出します。
要修正があると終了コード1で終わるので、CIにも組み込めます。

## 設定

プロジェクトのルートに `.ja-sunao.json` を置くと、対象外のパスと使わないルールを指定できます。

```json
{
  "exclude": ["docs/legacy/**"],
  "disable": ["emoji"]
}
```

`node_modules`、`vendor`、`dist`、`CHANGELOG.md` は最初から対象外です。
ルールのIDは [patterns.md](skills/ja-sunao/references/patterns.md) に一覧があります。

hooks を一時的に無効にしたいときは、環境変数 `JA_SUNAO_DISABLE=1` を設定してください。
