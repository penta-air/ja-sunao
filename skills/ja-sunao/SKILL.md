# ja-sunao

AIが書いた日本語は、言い回しより先に構成で見分けられる。
太字と箇条書きが多く、どの段落も同じ型で、最後に本文をなぞるまとめが付く。読み手はそこで機械が書いたと感じ、中身まで軽く見る。
このスキルは、そうした癖を検出して、内容を変えずに直す。

疑わしい箇所の検出は `scripts/scan.mjs` が機械的に行う。書いた本人は自分の書き癖に気づきにくいからだ。
直すかどうかは、文脈を見てあなたが決める。

## いちばん大事な規則：内容を変えない

直した文書を読んだ人は、そこに書かれていることを書き手が言ったこととして受け取る。
だから、元にないことを足すと、たとえ正しくても書き手の言葉をゆがめる。

- 元にない事実、数値、日付、人名、体験談を足さない。
  「理由は3つある」のような、元にない数の枠組みも足さない
- 確信の度合いを変えない。「かもしれない」を「決めた」にしない。逆も同じ
- です・ます体とである体、敬語の度合いを変えない
- 主張、例、条件、例外を消さない。削るのは情報の増えない繰り返しだけ
- 元の数値が食い違っていても直さず、ユーザーに伝える

具体的な中身がなくて直せない箇所（「さまざまなメリットがあります」の中身が素材にない、など）は、推測で埋めずにユーザーに伝える。

## 使い方

依頼の言葉から、次のどれかを選ぶ。

| 依頼の例 | すること |
|---|---|
| 「AIっぽいか見て」「どこが不自然か教えて」 | 診断だけ。書き換えない |
| 「自然にして」「AIっぽさを消して」「読みやすく直して」 | 診断してから直す |
| 日本語の文書を新しく書く | ルールに沿って書き、書き終えたら自己チェックする |

### 診断

1. `node <このスキルのフォルダ>/scripts/scan.mjs <file>` を実行する。
   文章が会話に貼られた場合は、一時ファイルに書き出してから実行するか、標準入力で渡す（`--kind doc|pr|commit`）
2. 出力の [要修正] と [助言] を、`references/patterns.md` の該当項目と照らして読む
3. `scan.mjs` が検出しない構成の癖（patterns.md の「目で見て直すもの」）も、本文を通して読んで確かめる
4. 指摘ごとに、該当箇所と、なぜAIっぽく見えるかと、直し方の方向を短く伝える。
   書き換えは頼まれるまでしない

### リライト

1. 診断と同じ手順で、直す箇所を洗い出す
2. [要修正] は直す。
   [助言] は、文脈上残す理由があれば残す（固有名詞の一部、リポジトリの慣習、文書の種類として自然、など）
3. 構成の直し（箇条書きを文に戻す、見出しを減らす）は、読み手が内容を取り違えるか探しにくくなっていると具体的に言えるときだけ行う。
   全項目に同じ変換を適用すると、かえって機械的に見えるからだ
4. 直したら、もう一度 `scan.mjs` を実行する。
   そのうえで、自分の書き換えに新しい癖が入っていないか確かめる。
   削った定型句を別の定型句で埋めていないか、ダッシュをコロンや括弧に逃がしていないか
5. 結果を返す。
   ファイルなら直接編集し、会話の文章なら直した全文を返す。
   何を直し、何を残したかを短く添える

### 新しく書くとき

`references/core-rules.md` のルールに沿って書く。書き終えたら `scan.mjs` で自己チェックし、[要修正] を直してから渡す。

Claude Code でこのプラグインを入れている場合は、hooks が同じことを自動で行う。
ファイルを書くと `scan.mjs` が実行され、[要修正] があれば差し戻される。コミットやPRの作成も、実行前にチェックされる。
hooks がない環境（`npx skills add` で入れた場合など）では、この自己チェックを自分で行う。

## 対象と設定

- 文書（.md / .mdx / .txt）、PR本文: 言い回しと構成の両方をチェックする
- コードのコメント、コミットメッセージ、PRタイトル: 短いので言い回しだけをチェックする。
  コードのコメントは助言のみ
- 改行: コードのコメント以外のすべてで、詰まりすぎた行（80字超か4文以上）と、空行のないまとまりの長さをチェックする（助言のみ）。
  箇条書きの項目の中も対象
- コード、引用、URL、フロントマターは対象外

プロジェクトのルートに `.ja-sunao.json` を置くと、対象外のパスや使わないルールを指定できる。

```json
{ "exclude": ["docs/legacy/**"], "disable": ["emoji"] }
```

hooks を一時的に無効にしたいときは、環境変数 `JA_SUNAO_DISABLE=1` を設定する。

## 参照ファイル

- `references/core-rules.md`: 日本語で書くときのルール。
  hooks がセッション開始時に読み込むものと同じ
- `references/patterns.md`: 検出パターンの一覧と直し方の例。
  診断とリライトのときに読む
